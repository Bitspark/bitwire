# Code of conduct

Discuss the work with care and respect. Explain disagreements with evidence;
acknowledge uncertainty and corrections. Evaluate proposals on their merits.

Harassment, threats, discriminatory or demeaning remarks, unwanted sexual
attention, publishing private information and persistent disruption are not
acceptable in this project's issues, pull requests or other shared spaces.

Report concerns privately to a repository maintainer. If no private maintainer
contact is available, GitHub's reporting tools provide a private route for conduct
that violates its policies. Do not post another person's private details in an
issue. Maintainers may remove content or restrict participation proportionately;
a maintainer named in a report should not handle it.
