# Changelog

## 0.4.0 — clean generic envelope replacement

One duplex Wire, exact byte paths, opaque ground ontos payloads, explicit
admission/receive/closure laws and one canonical binary envelope format.
All eight native declarations and packaged consumers use the new interface.
The active RPC/JSON engine contract, local return-address objects, historical
profiles, compatibility aliases and legacy test drivers are removed. This is
an intentional breaking release. Old published releases remain in immutable Git
history. Runtime behavior is implemented and tested independently in bitruntime.
