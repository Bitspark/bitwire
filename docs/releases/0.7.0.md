# bitwire 0.7.0

Go and TypeScript use public ontos 0.16.0 and the optional `ontos/wire` native
model. `HydratedValue` and `HydratedTuple` specialize that shared model for the
bitwire sending contract. They no longer define an independent tuple structure.

This is a source API cutover. Import Go ground values from
`github.com/bitspark/ontos/core/go` and the codec from
`github.com/bitspark/ontos/codec/go`. Import TypeScript ground values, codec and
data from `@bitspark/ontos-core`, `@bitspark/ontos-codec` and
`@bitspark/ontos-data`. The old Go mirror, TypeScript copied source, root ground
re-exports and `/ontos`, `/ontos-codec`, `/ontos-data` exports are removed, with
no compatibility aliases.

Charter W1 (ground messages), W2 (addressing), W3 (complete structure), W4
(send-only versus ownership) and W5 (local admission) remain unchanged. The
optional mixed value structure has a common owner; this does not widen raw
`Wire.Send`. The `bitwire/hydrated/1` grammar, reference fields, vectors and
counting rules remain bitwire-owned. Export/import and runtime recognition stay
above the structural model. Function, Stream and Cell remain library-owned.

Other language presentations retain the same declarations and their checked
ground mirror; only Go and TypeScript currently have a qualified optional native
value implementation. The independent old ground and hydrated vectors remain
acceptance oracles. Required checks retain all eight binding checks, packaged
consumers, release rehearsal and public installed-consumer verification.

This follows the owner's 4 November 2026 coordinated migration instruction.
Source delivery and package publication do not deploy existing services.
